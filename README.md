# Rečová cesta 2 – логопедическая игра с распознаванием слов и звуков

Веб-игра для тренировки произношения словацких звуков **R, Š, L, C, K**. Ребёнок
произносит **изолированный звук** («rrrr»), **слоги** (ra, ro, ru…) или **слова**
по картинке. Локальные нейросети оценивают попытку (0–3 звезды), робот двигается
по игровому полю. Логопед видит все попытки, слушает записи, исправляет оценки
и записывает, что ребёнок сказал на самом деле. Из этих пометок скрипт
`tools/compare_models.py` сравнивает модели.

Всё работает **на вашем компьютере**: аудио никуда не отправляется. Интернет
нужен только при первом запуске, чтобы скачать модели.
Литература и обоснование решений: [docs/zdroje.md](docs/zdroje.md).

## Запуск

Нужен Python 3.10 или новее (https://www.python.org/downloads/).

- **macOS:** двойной клик по **`Spustit hru.command`** (если macOS пишет, что разработчик
  не проверен: правый клик → «Открыть» → «Открыть», один раз).
- **Windows:** двойной клик по **`Spustit hru.bat`**.
- **Любая система:** `python start.py` (на macOS `python3 start.py`).

`start.py` показывает в консоли меню настроек (модель Whisper, фонемная модель,
устройство, порт, доступ из сети, строгая оценка, открыть ли браузер), сам создаёт
окружение `.venv`, ставит библиотеки (только в первый раз и когда `requirements*.txt`
меняются), запускает сервер и открывает игру. Первый запуск занимает несколько минут
(PyTorch ≈ 1 ГБ, модели ≈ 2 ГБ), дальше игра работает офлайн. Выбор запоминается в `data/start.json`.

Пока сервер работает, консоль принимает команды: `o` — открыть игру, `t` — панель
логопеда, `s` — состояние (какие модели загружены), `h` — справка, `q` — остановить.

Те же настройки можно задать параметрами, тогда меню не показывается:

```bash
python start.py --model medium --bez-fonem --port 8001     # модель Whisper, без фонем
python start.py --rychlo                                    # с прошлыми настройками, без меню
python start.py --menu --model small                        # меню с заранее выбранной моделью
python start.py --int8 --bez-fonem                          # для слабого компьютера (см. «Медленно распознаёт»)
python start.py --help                                      # все параметры (--device, --siet, --prisne, --bez-prehliadaca)
```

Вручную:

```bash
python -m venv .venv
# Windows:  .venv\Scripts\activate      Linux/macOS:  source .venv/bin/activate
pip install -r requirements.txt            # игра + Whisper
pip install -r requirements-phoneme.txt    # звуки: PyTorch + Transformers (большая загрузка)
python server.py
```

Игра: **http://127.0.0.1:8000**, панель логопеда: **http://127.0.0.1:8000/terapeut**.

Если фонемная модель не установлена или не скачалась, игра всё равно запустится:
слова оценивает только Whisper, а звуки и слоги оцениваются по тексту (ненадёжно,
игра об этом пишет).

## Модели и настройки

| Переменная | По умолчанию | Что это |
|---|---|---|
| `ASR_MODEL` | `small` | Whisper (faster-whisper) для слов: `tiny`, `base`, `small`, `medium`, `large-v3`, `large-v3-turbo` |
| `PHONEME_MODEL` | `phoneme:facebook/wav2vec2-xlsr-53-espeak-cv-ft` | wav2vec 2.0, распознаёт **фонемы IPA**; `none` — выключить |
| `WHISPER_DEVICE` | `auto` | `auto` / `cpu` / `cuda` (для обеих моделей) |
| `WHISPER_COMPUTE_TYPE`, `WHISPER_BEAM_SIZE` | `default`, `5` | параметры Whisper (`int8` — быстрее на слабом CPU) |
| `ASR_THREADS` | `0` | потоков CPU на модель; `0` — при двух моделях каждая получает половину ядер |
| `RECOGNIZE_TIMEOUT_SECONDS` | `30` | сколько игра ждёт оценку; более старую запись сервер пропускает |
| `MISSING_TARGET_MAX_STARS` | `1` | звёзд при заменённом звуке (`0` — строгий режим) |
| `HOST`, `PORT` | `127.0.0.1`, `8000` | адрес сервера |

```bash
ASR_MODEL=large-v3-turbo python server.py
# Windows PowerShell:  $env:ASR_MODEL="large-v3-turbo"; python server.py
```

Если в `ASR_MODEL` указать фонемную модель (`phoneme:…`), игра работает только с ней.

**Планшет в той же сети.** Браузер даёт доступ к микрофону только на `localhost` или по HTTPS:

```bash
python -m uvicorn server:app --host 0.0.0.0 --port 8000 --ssl-keyfile key.pem --ssl-certfile cert.pem
```

Сертификат проще всего сделать через `mkcert`.

### Медленно распознаёт / «server neodpovedá»

В консоли сервера после каждого слова видно, сколько считала каждая модель:

```
  ryba: slovo 1.1 s, hlásky 0.3 s, spolu 1.2 s (nahrávka 2.33 s)
```

Если при запуске написано `na grafickej karte nefunguje (… cublas64_12.dll …) – prepínam na CPU`,
на компьютере есть видеокарта NVIDIA, но не установлены библиотеки CUDA 12 — сервер сам
переводит модель на процессор. Чтобы не тратить на это время при каждом запуске, выберите
в `start.py` пункт **3 · Zariadenie → cpu** (или `--device cpu`); для работы на видеокарте
нужно установить CUDA 12 и cuDNN 9 от NVIDIA.

Нормально — 1–3 с. Если намного дольше (часто на ноутбуках с Windows без видеокарты):

1. включить в `start.py` пункт **8 · Výpočet int8** (`--int8`) — Whisper считает в int8;
2. выключить фонемную модель (пункт 2, `--bez-fonem`) — минус ~1,2 ГБ памяти и половина работы;
3. выбрать модель `base` вместо `small`.

Строка `⚠ ryba: vynechané – čakalo dlhšie ako 30 s` значит, что запись ждала, пока
досчитаются предыдущие, и сервер её пропустил: игра всё равно уже показала ошибку.

## Как устроена игра

1. **Настройка (заполняет взрослый):** код ребёнка (псевдоним), звук, **упражнение** и
   согласие родителя на сохранение записей. Упражнения идут от простого к сложному:
   - **Hláska** — звук отдельно («rrrr», «šššš»; у K — «k, k, k»), 5 повторов;
   - **Slabiky** — 6 слогов со звуком в начале и в конце (ra, ro, ru, re, ar, or);
   - **Slová** — 3 уровня: 1 – звук в начале слова, 2 – в середине или в конце,
     3 – в стечении согласных (проверяет `tests/test_words.py`).
2. **Игра:** картинка и задание → сначала правильно произносит взрослый → ребёнок
   нажимает 🎤 (или пробел) → запись останавливается сама после паузы → оценка → звёзды.
   - до **3 попыток** на задание; тишина попыткой не считается;
   - робот всегда хвалит или подбадривает; пока нет 3 звёзд и остались попытки, можно
     попробовать ещё раз (кнопка **Skúsiť znova** рядом с **Ďalej**), в зачёт идёт лучшая попытка;
   - во время игры шапка и подвал скрыты, на телефоне всё помещается на один экран;
   - конфетти за 3 звезды и за сундук; награда попадает в **альбом наклеек**
     (хранится в браузере по коду ребёнка);
   - кнопка **Ja** проигрывает только что сделанную запись прямо из браузера
     (работает и без согласия на хранение записей);
   - фишка проходит столько клеток, сколько получено звёзд, в конце — сундук с наградой.
3. **Панель «Pre dospelého»** (по умолчанию свёрнута, ребёнок её не видит): что услышала модель слов, ожидаемые и распознанные фонемы
   (например, `/r i b a/` → `/l i b a/`, «r→l»), режим оценки, задержка; кнопки
   **Uznať / Neuznať** исправляют оценку.
4. **Панель логопеда:** сводка по звукам и упражнениям, все попытки, прослушивание записей,
   исправление оценок, поле **«Naozaj povedal»** (разметка для сравнения моделей),
   экспорт CSV, удаление данных ребёнка.

### Запись звука (`static/recorder.js`)

- Браузер отдаёт сырые отсчёты (AudioWorklet), на сервер уходит **WAV 16 кГц**.
- Микрофон слушает всю игру и хранит последние ~150 мс, поэтому начало слова
  (особенно «k», «t») не обрезается; буфер короткий, чтобы не захватить слово взрослого.
  После игры микрофон освобождается.
- Порог «говорит / молчит» считается от шума комнаты (буфер перед нажатием и начало записи),
  а не задан числом. Если речи не было, запись на сервер не отправляется.
- Шумоподавление, эхоподавление и автоусиление браузера **выключены**: они ослабляют
  шипящие и свистящие (Š, C, S). Вернуть можно галочкой «Potlačenie šumu prehliadačom».
- Запрос на распознавание обрывается через 30 с (`RECOGNIZE_TIMEOUT_SECONDS`), сервер
  не принимает файлы больше 5 МБ (`MAX_UPLOAD_BYTES`).

На сервере запись декодируется один раз, обе модели работают параллельно и прогреваются
при старте.

## Как считается оценка

### Слова (`scoring.py`)

1. Текст нормализуется: нижний регистр, без пунктуации. Диакритика согласных
   (š, č, ž, ľ, ď, ť, ň) **сохраняется**, **долгота гласных** при сравнении игнорируется.
2. В распознанном тексте ищется слово, наиболее похожее на целевое («to je ryba»);
   пробуется и склейка двух соседних слов.
3. `skóre = 100 × (0,7 × сходство + 0,3 × уверенность модели)`, сходство — нормализованное
   расстояние Левенштейна по символам.
4. Если в слове **нет целевого звука** («lyba» вместо «ryba»), оценка ограничивается 74
   (не больше одной звезды; `MISSING_TARGET_MAX_STARS=0` — 0 звёзд).
5. **Точное совпадение** при наличии целевого звука всегда даёт 3 звезды.
6. Звёзды по порогам **60 / 75 / 91**, как в платформе LogoHra (Kováč et al., 2026).
7. Пустая запись, тишина и типичные «галлюцинации» Whisper («Titulky vytvoril…»,
   «Ďakujem.») дают результат «ничего не услышал».

### Звуки (`phonetics.py`)

1. **Ожидаемые фонемы** получаются по правилам словацкой орфографии (G2P): таблица букв,
   диграфы (ch, dz, dž), смягчение de/te/ne, оглушение в конце слова, v → u̯ в конце слога.
   Например `chlapec` → `x l a p ɛ ts`.
2. **Распознанные фонемы** даёт фонемная модель; они приводятся к общему виду
   (без ударения, `t͡s`/`t s` → `ts` и т. п.).
3. Фонемы **выравниваются** взвешенным Левенштейном (похожие фонемы, например d/ď, — 0,5,
   гласная ↔ согласная — 1,4).
4. Для **каждого вхождения целевого звука**: верно, заменён (на что) или пропущен.
   Увулярное /ʁ/ вместо /r/ (ráčkovanie) — ошибка.
5. Изолированный звук оценивается по доле согласных, которые являются целевым звуком.
6. Скор и звёзды — как у слов.

### Гибридный режим

В упражнении «Slová» при обеих моделях **слово** оценивает Whisper, а **целевой звук** —
фонемная модель. Если она с уверенностью ≥ 0,5 слышит замену или пропуск звука, звёзды
ограничиваются, как в п. 4. Фонемная модель может только снизить оценку. Для слогов и
звуков используется только фонемная модель: Whisper всегда пытается выдать слово.

## Сравнение моделей (для практической части)

1. Включите согласие на запись и пройдите все упражнения для каждого звука: для каждого
   задания **правильный** вариант и **намеренная ошибка** (r→l «lyba», š→s «saty», c→č «vajče»,
   увулярное R, пропуск звука). Хорошая цель — 3–5 дикторов, по 2 записи на задание.
2. В панели логопеда в поле **«Naozaj povedal»** напишите, что было сказано на самом деле
   (`lyba`, `la`, `lll`); для правильных попыток достаточно нажать ✓.
3. Скачайте **«Zoznam nahrávok»** (`manifest.csv`) и запустите:

```bash
python tools/compare_models.py --manifest manifest.csv \
  --models small,medium,large-v3-turbo,phoneme:facebook/wav2vec2-xlsr-53-espeak-cv-ft
```

Каждая модель оценивается **той же логикой, что и игра** (`scoring.analyze`); для каждой
пары «Whisper + фонемная модель» считается и гибридный режим. Результаты:
`results/<дата>/summary.md`, `summary.csv`, `details.csv`, `raw_*.jsonl`.

| Метрика | Что показывает |
|---|---|
| WER, CER / PER | ошибки распознавания слов и символов / фонем |
| target_acc | как часто модель верно решает «звук правильный / нет» |
| **false_accept** | доля **неправильных** произношений, которые модель приняла (главная метрика) |
| false_reject | доля **правильных** произношений, которые модель отвергла |
| error_recall / precision | насколько хорошо модель ловит ошибки |
| lat_mean, lat_p95, RTF, load_s | задержка, скорость относительно длины записи, время загрузки |

Всё считается отдельно для звуков, слогов и слов. «Принято» = не меньше 2 звёзд
(`--accept-stars`). Опции: `--limit 10`, `--no-hybrid`.

`python tools/rescore.py` пересчитывает сохранённые попытки текущей логикой (без моделей,
база только читается) и показывает, что изменилось.

## Структура

```
start.py             запуск одним файлом (.command — macOS, .bat — Windows)
server.py            FastAPI: страницы и REST API
asr.py               модели распознавания: Whisper (слова) и wav2vec 2.0 (фонемы)
scoring.py           оценка слов, гибридная комбинация, оценка попытки (analyze), WER/CER
phonetics.py         словацкий G2P, выравнивание фонем, оценка звука
db.py                SQLite: дети (псевдонимы) и попытки
config.py            настройки
data/words.json      словарь: 5 звуков × (звук, 6 слогов, 3 уровня слов)
static/              игра (index.html, game.js, recorder.js), панель логопеда (therapist.*), common.js
tools/               compare_models.py — сравнение моделей, rescore.py — пересчёт попыток
docs/zdroje.md       литература и обоснование решений
tests/               unit- и интеграционные тесты
```

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/words`, `/api/config` | словарь и настройки (какие модели загружены) |
| POST | `/api/children` | создать или обновить ребёнка (код + согласие) |
| POST | `/api/recognize` | аудио + задание (`exercise` = `sound`/`syllable`/`word`) → оценка |
| POST | `/api/attempts/{id}/override`, `/api/attempts/{id}/label` | исправление оценки, разметка |
| GET | `/api/stats/{code}`, `/api/attempts`, `/api/attempts/{id}/audio` | статистика, попытки, запись |
| GET | `/api/export.csv`, `/api/manifest.csv` | экспорт |
| DELETE | `/api/children/{code}` | удаление всех данных ребёнка (GDPR, ст. 17) |

Документация API: http://127.0.0.1:8000/docs

## Приватность

- ребёнок хранится только под кодом, имя не запрашивается;
- без согласия запись удаляется сразу после распознавания;
- все модели работают локально, сторонним сервисам ничего не передаётся;
- по умолчанию сервер слушает только `127.0.0.1`;
- `data/attempts.sqlite3` и `data/audio/` — личные данные, не передавайте их вместе с кодом.

## Ограничения

- Ни одна модель не дообучена на детской словацкой речи. У Kováč et al. (2026) даже
  **после** дообучения на словацкой детской речи WER был 15–16 %.
- Фонемная модель многоязычная; правила G2P упрощены (без ассимиляции звонкости внутри слова).
- Оценка звука — сравнение с ожидаемой фонемой, а не клиническая оценка артикуляции;
  решение всегда за взрослым (кнопки Uznať / Neuznať).
- Словарь рабочий, перед использованием с детьми его должен проверить логопед.
- Игра не заменяет логопеда и не проходила клиническую проверку.
